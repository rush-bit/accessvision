# accessvision

AccessVision is a web-based, AI-assisted platform designed to help identify and organise information about the accessibility of public infrastructure.
The platform will allow a user to upload a photograph of a building entrance, pedestrian pathway, staircase or ramp. A computer-vision model will analyse the photograph to identify supported visible infrastructure features and potential obstacles. The user will then verify additional accessibility-related information that cannot reliably be inferred from the image.
